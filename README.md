Kades Cup 2025 Adan-Adan - Codemagic-ready Flutter project
=========================================================

This archive is prepared to be uploaded directly to Codemagic (https://codemagic.io/start)
to build an Android APK automatically.

Files included:
- lib/main.dart       (full app code: landscape, start match, service-point system to 30)
- pubspec.yaml
- codemagic.yaml     (Codemagic build workflow for Android APK)
- README.md

How to build on Codemagic:
1. Go to https://codemagic.io/start and sign in (use Google for quick login).
2. Click "Start new build" or "Upload" and choose this ZIP file.
3. Choose the workflow (default) and click "Start build".
4. Wait ~2-5 minutes. When finished, download the generated APK.

Notes:
- The app is locked to landscape orientation.
- Service-point scoring system (single game to 30).
- Shuttlecock small icon indicates current server (left or right).
- Start Match screen before scoreboard opens.
- No external assets required.
